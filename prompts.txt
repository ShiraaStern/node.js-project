[שאלה 1 - שיעור 1-2: הגדרת השרת והמבנה הבסיסי]
פרומפט:
"איך אני מקימה שרת Express בסיסי שמחזיר תשובות בפורמט JSON ותומך ב-Routes שונים?"

תשובה/פתרון:
יוצרים קובץ app.js, מייבאים את express, ומגדירים את ה-Middleware לקריאת JSON באמצעות express.json(). 
לאחר מכן מגדירים את ה-Endpoints הבסיסיים או מחברים ראוטרים נפרדים לכל ישות במערכת.

--------------------------------------------------------------------

[שאלה 2 - שיעור 3: מימוש CRUD מלא]
פרומפט:
"איך נכון לממש פונקציות CRUD עבור ישות כמו Courses כולל בדיקת תקינות הקלט והחזרת קודי סטטוס מתאימים?"

תשובה/פתרון:
בכל בקשה יש לבדוק:
1. GET: החזרת רשימה מלאה (200 OK) או אובייקט לפי ID. אם לא נמצא - 404 Not Found.
2. POST: בדיקה שכל שדות החובה קיימים ב-req.body. אם חסר - 400 Bad Request. אם תקין - 201 Created.
3. PUT: עדכון האובייקט לפי ID. אם לא נמצא או חסר קלט - 400/404.
4. DELETE: מחיקה לפי ID. אם הצליח - 200 OK, אם לא נמצא - 404 Not Found.

--------------------------------------------------------------------

[שאלה 3 - שיעור 4: ארכיטקטורה והפרדת אחריות (MVC / Architecture)]
פרומפט:
"איך לפצל את הקוד באופן נקי בין Data, Services, Controllers ו-Routes?"

תשובה/פתרון:
1. Data (data/): מנהל ומייצא את מערכי הנתונים הסטטיים.
2. Services (services/): מכיל את הלוגיקה העסקית בלבד (חיפוש, הוספה, עדכון, מחיקה) ללא תלות ב-req/res.
3. Controllers (controllers/): מטפל בבקשות HTTP, שולף פרמטרים מ-req, קורא ל-Services ומחזיר תשובות res.json().
4. Routes (routes/): מגדיר את הנתיבים והמתודות (GET, POST וכו') ומפנה ל-Controllers המתאימים.

--------------------------------------------------------------------

[שאלה 4 - שיעור 5: אבטחה ו-Middleware לאימות]
פרומפט:
"איך יוצרים Middleware שבודק Header מותאם אישית בשם auth-key וחוסם גישה אם המפתח אינו תקין?"

תשובה/פתרון:
מגדירים פונקציית Middleware שמקבלת (req, res, next).
שולפים את ה-Header באמצעות req.get('auth-key').
משווים למפתח הסודי:
- אם חסר או לא תואם -> מחזירים res.status(401).json({ message: "Unauthorized" }).
- אם תואם -> קוראים ל-next() כדי להמשיך לראוטר הבא.

--------------------------------------------------------------------

[שאלה 5 - בדיקת תקינות הראוטים וסידור נתיבים]
פרומפט:
"איך מחברים את קבצי ה-Routes לשרת הראשי app.js באמצעות app.use?"

תשובה/פתרון:
מייבאים את ה-Routers ב-app.js ומחברים אותם עם נתיב בסיס:
app.use('/courses', coursesRouter);
app.use('/students', studentsRouter);
app.use('/enrollments', enrollmentsRouter);
